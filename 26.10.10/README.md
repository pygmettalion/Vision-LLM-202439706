
# Student Score Analysis

## Description
5명의 학생 성적 데이터를 분석하는 Python 프로그램입니다.

## Requirements
- Python 3
- NumPy

## Installation
pip install numpy

## How to Run
python section_project.py

## Features
1. 학생 이름 추출
2. 전체 성적을 1차원 배열로 변환
3. 85점 이상 성적 개수 계산
4. 학생별 평균 점수 계산
5. 최고 평균 점수 학생 확인
6. 전체 최고 점수와 해당 학생 및 과목 확인
